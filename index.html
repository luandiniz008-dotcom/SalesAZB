Configurações

Área do administrador: mês vigente e planilha mestre.
Mês vigente para previsão
Apenas o mês definido aqui fica disponível para os SAMs lançarem a previsão — assim ninguém previsiona o mês errado por engano. Altere quando abrir um novo ciclo (normalmente no início de cada mês).
Etapa da previsão que os SAMs preenchem
A cada mês o dashboard passa por 3 etapas: SE (previsão inicial, início do mês), MM (ajuste, dia 15) e FATURADO (confirmação do que foi faturado de fato, 1 dia após o fechamento do mês). Escolha aqui qual etapa está ativa agora — nenhum SAM decide isso por conta própria.
A planilha mestre define quem são os SAMs e quais contas/produtos cada um previsiona — extraída das colunas B (SAM/KAM) e F (SKU) da sua planilha. Para atualizar o cadastro (novos clientes, novos produtos, novos SAMs), importe uma nova planilha no mesmo formato abaixo.

Gerar dados de teste (previsão aleatória)
Isso grava dados de verdade no armazenamento — sobrescreve a previsão SE, MM e a confirmação de faturamento de todos os SAMs para o mês escolhido. Use só em ambiente de teste/homologação.
Gera SE aleatório (10–99) para 3 a 8 contas por SAM, repete o mesmo valor no MM, e confirma 100% como "Faturado". Usa uma semente fixa — os números batem exatamente com os que a Claude mostrou na conversa, para você conferir manualmente contra a planilha final.
